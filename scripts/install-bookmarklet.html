📋 Cómo usarlo

  1. Arrastra el botón «Sincronizar con HABITS» a tu barra de favoritos (Ctrl+Shift+B para mostrarla en Chrome).
  2. Entra a class.utp.edu.pe y haz login.
  3. Haz clic en el favorito «Sincronizar con HABITS».
  4. ✅ Listo. Tus tareas aparecen en HABITS (app y recordatorios de Hermes).

Hazlo cada vez que el profe suba nuevas entregas (toma 1 segundo).

🔧 ¿El botón no se instaló con el script?

Descarga el script desde C:\EATON\HABITS\scripts\utp-sync-bookmarklet.min.js, copia TODO su contenido y pégalo en la URL de un marcador nuevo.
